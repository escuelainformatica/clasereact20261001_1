# principios de codigo

* SRP (Single Responsibility Principle): Cada módulo o clase debe tener una única responsabilidad.
* DRY (Don't Repeat Yourself): Evitar la duplicación de código, promoviendo la reutilización y la mantenibilidad.
* KISS (Keep It Simple, Stupid): Mantener el código lo más simple posible, evitando complejidad innecesaria.
* YAGNI (You Aren't Gonna Need It): No implementar funcionalidades hasta que sean realmente necesarias.
* WYSIWYG (What You See Is What You Get): El diseño y la interfaz deben reflejar fielmente el resultado final que verá el usuario.
